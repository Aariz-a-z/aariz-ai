Northwind Marine

A stand-in for a customer's website. It has nothing to do with the chatbot beyond the one script tag at the bottom of this file.

The launcher sits in the corner. Everything inside it runs in an iframe served from a different origin, so this page cannot read the conversation and the widget cannot restyle this page.

This page must be opened at http://localhost:5100. Opening it at 127.0.0.1 is a different origin, and the allowlist — correctly — will refuse it.
